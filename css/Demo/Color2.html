Explanation of the Code

color: hsl(0, 100%, 50%); This CSS property sets the text color using HSL values.

  • 0: Represents the hue (0 degrees on the color wheel is red).
  • 100%: Represents the saturation (fully saturated color).
  • 50%: Represents the lightness (a pure, non-darkened or brightened red).
