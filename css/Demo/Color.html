In color there are three basic colors

  • Red
  • Green
  • Blue

color has a

  • 1. Hex code
  • 2.short Hex code
  • 3.RGB absolute
  • 4.keywords

example

1.Hex code
  • #000000 -black
  • #FF0000-red
  • #00FF00- green
  • #0000FF-blue

2. RGB Absolute

  • rgb(0,0,0)-black
  • rgb(255,0,0) -red
  • rgb(0,255,0)- green
  • rgb(0,0,255)-blue

3. Keywords

  • black
  • red
  • green
  • blue
